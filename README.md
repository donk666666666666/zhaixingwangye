# 历井抚星 · 暑期社会实践静态网站

北京科技大学“历井抚星”社会实践队的暑期专题网站，包含三个页面：

- `index.html`：首页，展示团队简介、合作机构入口和陪伴活动
- `team.html`：团队实践记录，包含 8 天实践时间线、实践数据与活动掠影
- `institutions.html`：机构介绍，包含 7 家机构与 2 次城市外展资料

静态网站不需要数据库和后端，浏览器直接访问 HTML 文件即可。

## 当前已替换的内容

- 队伍名称：历井抚星社会实践队
- 所属学校：北京科技大学
- 所属分队：北京科技大学“摘星实践团”
- 实践地点：陕西省西安市
- 机构列表：千千爱特殊教育机构、小凡星特殊培训、心思维融合教育培训中心、心心特殊儿童发展中心、陕西慧灵社会工作服务中心、拉拉手特殊教育中心
- 城市外展：清凉山公园、兴庆宫公园
- 实践记录：8 天时间线，包括脸谱绘画、米粒画、烘焙饼干、中药香包、绘画互动、街头科普、彩泥与合唱、串珠手链

## 还需要替换的内容

1. `team.html`：填写指导老师和团队成员姓名。
2. `institutions.html`：补充千千爱、小凡星、心思维、心心、陕西慧灵的公众号或官网信息，以及心心特殊儿童发展中心的地址。
3. 所有页面的 `待填写` 和联系邮箱，替换为真实联系方式。
4. `assets/img/`：把占位插画替换成有授权的真实照片，儿童面部要打码或获得监护人书面授权。
5. 机构简介和联系电话请与各机构官方核对后再发布。

## 本地预览

直接双击 `index.html` 即可在浏览器打开，也可以运行：

```bash
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080`。

## 部署到云服务器

把整个文件夹上传到服务器，例如 `/var/www/special-care-site`，配置 Nginx：

```nginx
server {
    listen 80;
    server_name 你的域名或服务器IP;

    root /var/www/special-care-site;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

然后执行：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

并在云服务器安全组和宝塔防火墙中放行 `TCP 80`。

## 域名与备案

- 不买域名也可以先用 `http://服务器IP/` 访问。
- 正式发布建议购买域名，并配置 HTTPS。
- 服务器在中国大陆时，绑定域名通常需要先完成 ICP 备案。
- 如果暂时不想买域名，可以使用 GitHub Pages、Vercel、Netlify、Gitee Pages 等免费静态托管。

## 上线前检查清单

- 机构名称、地址、电话是否与官方一致
- 儿童照片是否获得监护人授权，面部是否处理
- 是否已删除示例数据和占位联系方式
- 手机、平板、电脑三种尺寸是否都能正常浏览
- 域名解析是否生效，HTTPS 是否配置
- 是否已请指导老师和机构负责人复核内容
